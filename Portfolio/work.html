01 / JAVA · DESKTOP · NETWORKING FLAGSHIP

YSH Terminal

YSH (Yousuf Shell) is a Java desktop shell with a graphical terminal interface. It has real filesystem operations, custom commands, command history, themes, a calculator, notes, developer mode and LAN chat with file sharing.

It has moved through several versions: the early CLI builds, the first GUI, v7, v8 and the current v10 line. Each version has been a chance to rebuild parts of it and learn something new.

CLI V1–V5 → FIRST GUI v5 → V7 → V8 → Linux v8 → v8.1.4 Latest → V10 Beta
