# Yousuf — Portfolio

A personal portfolio built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — introduction and selected work
- `work.html` — project details
- `archive.html` — live public GitHub repository list
- `about.html` — background, community work and tools

## Run locally
Open `index.html` in a browser, or serve this directory with any static file server.

The project archive uses the public GitHub API. Project screenshots are loaded from the repositories that contain them, with a few older screenshots reused from the existing portfolio repository.
