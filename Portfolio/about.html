01 Where I'm coming from

Curious about the whole stack — from the interface down to the system underneath.

Currently I'm a second-year Diploma student in Computer Science and Engineering @ Quli Qutub Shah Polytechnic, Hyderabad. I enjoy learning by making things that I can actually run, use, test and improve.

I started with programming fundamentals and web projects, then found myself spending more time on Java desktop software, command-line tools, networking and system-level ideas. I like interfaces too, especially when the interaction has a reason to exist.

I'm also getting into electronics and hardware. Hakin Pad has been one way to move beyond the screen and make something physical.

Outside programming, I enjoy roller skating, sketching, athletics and sports.
