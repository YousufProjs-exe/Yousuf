01 A short introduction

I learn by building something, breaking it, and figuring out why.

Currently I'm a second-year Diploma student in Computer Science and Engineering @ Quli Qutub Shah Polytechnic, Hyderabad. I spend most of my time making software, then going a little deeper into how it works.

That usually means Java desktop applications, command-line tools, web interfaces, networking experiments and the occasional hardware project.

My main project is YSH Terminal — a Java shell that grew from a small experiment into a project with real file operations, LAN communication and its own set of tools.
